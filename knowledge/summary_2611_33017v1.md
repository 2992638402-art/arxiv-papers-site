## 📝 摘要

RGB-based video object segmentation (VOS) remains brittle under fast motion and adverse illumination. Event cameras preserve signal under blur and challenging exposure, but provide little evidence when motion slows. Interaction can restore object state for subsequent propagation, yet promptable event methods merely address single windows. We formalize event-based Promptable Video Segmentation (ePVS), where prompts at arbitrary windows initialize, correct, or introduce objects and predictions. We present Event Memory-As-Prompt Segmentation (E-MAPS), which transfers a pretrained promptable segmenter to event streams and learns propagation and correction. Event-to-Token (E2T) aligns recurrent event features with pretrained representations while preserving prompt-conditioning priors. Memory-Aware Prompting (MAP) converts object-conditioned history into sparse prompts, allowing memory and user inputs to share one decoder pathway efficiently. We construct Event-View Masklets (EViM) from 206K aligned RGB-event pairs and 620K masks for two-stage representation transfer and native event-video learning, and establish three training-disjoint benchmarks. E-MAPS leads prompt-once and interactive ePVS across all three benchmarks while being more efficient. It further demonstrates strong performance on zero-shot object tracking benchmarks.
