Edge-Native Temporal--Graph Dual-Expert Inference for Dexterous Grasp Classification

arXiv ID: 2610.14926
分类: cs.RO
发布时间: 2026-10-10

📄 论文信息

  • 作者: Jiajian Zheng, Bin Zhang, Wen Fan, Yanan Liu
  • PDF: 下载
  • arXiv 链接: 查看

📝 摘要

Multi-finger hands contact objects at different times, so a global close command can overload early-contact fingers while others are still moving. Dense tactile arrays address this problem but add hardware, calibration, bandwidth, and computation. We present an edge-native pipeline that uses only built-in joint-angle and pre-use-calibrated actuator-load feedback to recognize the grasped object and predict an independent Stop event for each finger. Four samples and their first differences form a 4-by-20 contact-evolution window. At its core is a heterogeneous dual-expert architecture, termed DualExpert, that assigns complementary tasks to a Temporal Convolutional Network (TCN) and a Finger Graph Filter Network (FGFN). The TCN models short-term contact evolution and supplies all five Stop probabilities, while the FGFN encodes finger topology and contributes only to object classification. Fixed 0.7/0.3 class-probability fusion reaches 93.78% trajectory-level classification accuracy on 225 held-out trials, improving the standalone TCN and FGFN by 4.00 and 2.22 percentage points, respectively. The TCN Stop path attains 95.25% F1. The dataset contains 1,500 automatically collected trajectories from five object instances. In Flash deployment, mixed accelerator execution retains 93.78% classification accuracy and 94.84% Stop F1 with 2.890ms mean inference time and 9.172ms mean sample-to-stop latency. Across 50 physical trials, the system achieves 96.00% recognition and 98.00% grasp success while the complete embedded board draws approximately 0.80~W.
