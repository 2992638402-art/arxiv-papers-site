A Nonconvex Framework for Joint Sparse Sample Weighting and Parameter Estimation

arXiv ID: 2610.33957
分类: math.OC, cs.LG, stat.ML
发布时间: 2026-10-25

📄 论文信息

  • 作者: Hassan Nojavan, Chul Moon, Miju Ahn
  • PDF: 下载
  • arXiv 链接: 查看

📝 摘要

We propose a joint sparse sample weighting and parameter estimation (SWAPE) framework that jointly optimizes model parameters and sample weights to train a model while simultaneously assigning an individual weight to each training data point. Our framework accommodates several widely used loss functions for the model parameters, including convex, weakly convex, and difference-of-convex loss, and weakly convex sparsity functions to control the complexity of the sample weights. To solve the resulting bivariate problem, we propose an alternating minimization method in which the subproblems for updating the model parameters and weights are each approximated using majorize-minimize techniques. We provide several approximation methods for the loss functions considered in this paper, and show the overall algorithm's convergence. Numerical experiments on various learning tasks and data anomaly settings demonstrate the effectiveness of the proposed framework in minimizing the impact of undesirable data points compared to benchmark methods.
