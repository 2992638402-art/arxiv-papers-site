DS2Agent: Holistic Device Agents for Accelerated Embedded Board-Level Design

arXiv ID: 2611.25774
分类: cs.MA
发布时间: 2026-11-19

📄 论文信息

  • 作者: Hongbin Yang, Chi Zhang, Yinhao Xiao, Runyu Pan, Yanni Yang, Xiuzhen Cheng
  • PDF: 下载
  • arXiv 链接: 查看

📝 摘要

Embedded board-level development demands extensive expertise, from component selection and device characteristics to interface configuration, driver writing, and system composition. Recently, LLM-based agents have shown strong capabilities, raising the prospect of automating board-level design tasks. However, existing agents either target chip-level design or treat datasheets as static text, offering little guidance on whether a specific component should---or even could---be used for a given board-level design. Moreover, without touching real hardware, they hallucinate incorrect details. To fill this gap, we present {\setlength{\fboxsep}{1pt}\href{https://anonymous.4open.science/r/DS2Agent-9FE8/}{\fcolorbox{blue}{white}{DS2Agent}}}, an open-source framework that constructs interactive agents from device datasheets. Each agent comprises three models: a knowledge model supporting retrieval and question answering; a digital-twin model capturing the physical functionality of the device; and an interface model supporting driver development and system integration. To suppress hallucinations, we also allow optional connections to real devices, so that the agent can calibrate its internalized knowledge against the device. We evaluate DS2Agent on ten devices spanning seven functional categories. Compared with the baseline, the DS2Agent-augmented agent improves the question-answering score from 87 to 97 out of 100 while using 44.8% fewer tokens. For driver generation, it reduces average token usage per device by 72.9%. For system integration, it reduces total token usage across three FreeRTOS applications by 29.7%.
