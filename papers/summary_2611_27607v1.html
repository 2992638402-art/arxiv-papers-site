Tasklets: A Unit-Test Benchmark for Language Model Architectures

arXiv ID: 2611.27607
分类: cs.CL, cs.LG
发布时间: 2026-11-20

📄 论文信息

  • 作者: Zayd Muhammad Kawakibi Zuhri, Munachiso Samuel Nwadike, Kentaro Inui, Alham Fikri Aji
  • PDF: 下载
  • arXiv 链接: 查看

📝 摘要

We introduce Tasklets, a benchmark of small synthetic tasks for evaluating the computational capabilities of language model sequence-mixing layers. These tasks probe foundational capabilities such as recall, sequence manipulation, and state tracking. Such tasks are widely used in architecture research, but differences in task selection, formulation, and evaluation make comparisons across studies difficult. Tasklets brings these tasks together, organizing them by the capabilities they test and providing a shared setup for evaluating how different architectural layer types learn fundamental computations. We compare a broad range of layer types through controlled experiments with small models. Our task implementations and evaluation code support reproducible, low-cost testing of new architectural proposals: https://github.com/zaydzuhri/flame/tree/tasklets.
