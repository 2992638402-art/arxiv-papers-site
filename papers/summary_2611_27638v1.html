Seeing Is Not Steering: Where Verifiable Reasoning Can Enter an End-to-End Driving Planner

arXiv ID: 2611.27638
分类: cs.RO, cs.CV
发布时间: 2026-11-20

📄 论文信息

  • 作者: Gautam Kumar Jain, Atharva Mahindrakar, Shubham Phoolari, Ignacio Alvarez, Carsten Markgraf, Constanze Hungar, Christoph Lauer, Julian Staehler
  • PDF: 下载
  • arXiv 链接: 查看

📝 摘要

Driving models that reason may describe a hazard correctly while choosing their path for other reasons. We study where scene reasoning can enter an end-to-end planner so its influence can be checked. We freeze Drive-JEPA and use a fine-tuned vision-language model to state scene facts. Although fine-tuning improves fact accuracy, the two learned components we test show no detectable benefit from reading them. A rule-based fact check instead rejects or shortens paths that contradict the facts, linking each intervention to a stated fact. On the frozen planner alone, it gains 2.4 EPDMS points on navhard. Its 2.0-point margin over a control that changes the same frames without consulting facts remains statistically uncertain. A diagnostic using exact facts from maps and annotations yields a 3.6-point margin over its corresponding control, with a 95% confidence interval above zero. Separately, a path scorer and plan memory that read no stated facts raise navhard from 41.2 to 51.8. Bounding travel distance using the reasoner's facts adds 0.3 there and reduces navtest by 2.0. The fact check makes each intervention auditable, while the driving value of the reasoner's facts remains unresolved.
